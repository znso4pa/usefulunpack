# BGI / Ethornell archives (.arc)

1. The `.arc` suffix is shared by unrelated formats. Check for BGI/Ethornell evidence and list entries before applying its decoder. Some versions need extension-based detection.
2. Extract a representative entry and identify whether its contents need a DSC decompression or BSE handling. Report parsing failures at the index and payload stages separately.
3. UsefulUnpack has a BGI extraction path. If a replacement must be BGI-compatible, preserve the original and request a verified writer or another engine-supported patch path.
