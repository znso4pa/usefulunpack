# 工具调用规范

每次调用前，用一句话记录这一步的目的、目标、操作模式和预期影响，让用户能核对执行依据。

| 模式 | 调用前写明 |
| --- | --- |
| 只读 | 要读取或检查的对象，以及结果用于确认哪个问题。 |
| 新建 | 输入、输出位置和将产生的文件。 |
| 修改 | 将改变哪些现有文件，以及已经确认的修改范围。 |
| 删除或覆盖 | 受影响的对象和是否可恢复，并核对用户的明确授权。 |

使用技能目录中的实际工具名与结构化参数。例如，需要确认一个归档的条目时，先用只读模式调用 `ARCHIVE_LIST`。用户要求生成新归档时，用 `COMPRESS` 并明确源目录、目标路径和格式。签名扫描使用 `SCAN`，指定切出文件时属于写入操作。

调用后记录实际状态、产物以及工具返回的任务 ID 或日志 ID。根据结果决定后续步骤，只有前置步骤达到预期才继续执行依赖它的操作。
