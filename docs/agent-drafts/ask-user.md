# 需要向用户确认的情况

如果拿不准用户指的是哪个文件、要做哪种操作、产物放在哪里，或现有文件怎么处理，先暂停受影响的步骤并提问。可以通过已授权的只读检查缩小范围，再把仍需确认的选项和影响说清楚。

- **目标不明确。** “系统里找到两份同名归档。你要处理项目目录里的这份，还是备份目录里的那份？”
- **输出冲突。** “输出位置已有同名文件。你要覆盖旧文件、另存为新文件，还是取消封包？”
- **不可逆的操作缺少明确授权。** “永久删除后无法从回收站恢复。你要永久删除这三个文件，还是移入回收站？”

等用户明确回复后，按确认的对象和方式继续。确认只适用于这次操作以及提问中列出的范围。
