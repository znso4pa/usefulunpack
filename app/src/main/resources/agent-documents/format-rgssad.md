# RPG Maker XP RGSS archive (.rgssad)

1. Use `uu l` to inspect the archive via the RGSS reader. Identify the project as RPG Maker XP before selecting a pack target. The RGSS read path is shared across XP, VX and VX Ace.
2. Use `uu x` for exact paths or a full copy. Record engine-related filenames and verify sample scripts or assets after extraction.
3. Use `uu c "stage" "rebuild/Game.rgssad" -f rgssad` for XP. Keep the expected archive basename in a separate safe directory and check the runtime.
