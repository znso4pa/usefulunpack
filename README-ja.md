# UsefulUnpack

[**中文**](README-zh.md) | [**English**](README.md) | [**繁體中文**](README-zh-TW.md) | [**日本語**](README-ja.md)

軽量 Android ファイルマネージャー & アーカイブ圧縮・解凍ツール

**XP3**（吉里吉里）、**PFS**（Artemis）、**NSA/SAR**（NScripter）、**YPF**（YU-RIS）、**RGSS**（RPG Maker XP/VX/VX Ace）、**KSD**（吉里吉里2）、**RPA**（Ren'Py）、**ISO 9660**、および **ZIP**、**7z**、**RAR**、**TAR**、**GZIP**、**BZIP2**、**XZ**、**ZSTD**、**LZMA**、**LZ4** などの汎用形式（圧縮/解凍対応）。Rust ネイティブコア。

## マルチウィンドウ FAQ

**1. 3つのウィンドウで同時解凍すると OOM の可能性は？**

現行版では**3つのウィンドウが同時に解凍することはありません**。解凍/圧縮はグローバル単一ロック（`OperationLock`）で直列化され、2番目以降の解凍は「処理中」トーストで拒否されます。そのためメモリ負荷は単一ウィンドウ解凍と同じで、OOM の可能性は極めて低いです。実際のメモリ源は**単一アーカイブ内の並列デコード**（RAR 非ソリッド ≤4 スレッド、ZIP エントリ単位並列 ≤32MiB バッチ）で、>64MB の大メンバーはストリーム解凍でバッファリングしません。「並列解凍スレッド」設定はウィンドウ別ではなくグローバルです——1つのウィンドウで 4/8 スレッドを使うとメモリ予算を使い切ります。

**2. 複数ウィンドウで同じファイルを開いている場合、ウィンドウ1の変更は他に即時反映されますか？**

各ウィンドウは独立したディレクトリ監視（FileObserver）を持ちます。**両方のウィンドウが同じディレクトリにある場合**（例：両方 `/Download`）、どちらかのウィンドウでの解凍/リネーム/削除でディレクトリイベントが発生し、両方の監視が受け取ってそれぞれ更新——**即時同期**されます。異なるディレクトリのウィンドウ同士は干渉しません。

同じアーカイブ（分巻も含め、例 `name.zip.001/.zip` は同一とみなす）は**同時に2つのウィンドウで開くことはできません**：同アーカイブ排他ロック（OpenArchiveRegistry）により、2つ目のウィンドウでは「このアーカイブは『ウィンドウN』で開かれています」と表示され、そのウィンドウへ自動ジャンプします。ロックはプレビュー/編集中に保持され、ダイアログを閉じるかウィンドウを閉じると解放されます。

**3. プレビュー中にウィンドウを切り替えられますか？**

はい。アーカイブプレビューは**現在のウィンドウ内に表示**され（モーダルではありません）、ViewPager は常にスワイプ可能です——プレビューしながら左右スワイプでウィンドウを切り替えられ、各ウィンドウのプレビュー/選択状態は互いに干渉しません。プレビューから全体検索を開いても、検索を閉じるとプレビューに戻ります。

**4. パス/ファイル選択で新しいウィンドウを開けますか？**

はい。一般設定 →「パス/ファイルの選択方法」で「パス選択ダイアログを開く」（既定）と「新しいウィンドウで選択」を切り替えられます。後者は選択操作（検索範囲/解凍先/ZIP追加/圧縮先など）で新ウィンドウを開いて閲覧・選択し、選択後に自動で閉じて元のウィンドウへ戻ります（元のウィンドウの状態は保持）。戻るキーで選択をキャンセルします。

## インストール

[Releases](https://github.com/znso4pa/usefulunpack/releases) から最新のAPKをダウンロード。

Android 8.0（API 26）以上。

## ビルド

```bash
bash build.sh
```

各形式を独立した `.so` にコンパイルし、Gradle で APK にパッケージ。
